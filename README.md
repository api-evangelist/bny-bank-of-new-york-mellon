# BNY — removed at the company's request

The Bank of New York Mellon asked for this repository's removal on **2026-09-04**,
through the Brand Protection Lead in its legal group, and the request was honored.

Everything that was here is deleted from this repository's current contents: the API
descriptor, 49 scoring runs, and all derived artifacts (authentication, collections,
finops, openapi, plans, rate-limits, screenshots, security, agentic-access). The
repository itself remains only as this notice so existing inbound links do not break.

On apis.io, BNY keeps a minimal record — name, one corporate sentence, and a link to
[bny.com](https://www.bny.com/) — and is **unrated**: no score of any kind, not a zero.

BNY is on the permanent delisting registry
([`network/_data/delisted.yml`](https://github.com/api-search/network/blob/main/network/_data/delisted.yml)),
which every harvest, enrichment and scoring pipeline consults before touching anything,
so automated re-discovery will not re-add them.

Removal requests are honored on request: kin@apievangelist.com.
